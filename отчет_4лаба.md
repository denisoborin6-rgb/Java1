# Задание 1

## Задача 1
### Текст задачи
Обобщенная коробка. Создайте сущность Коробка, которая обладает следующими характеристиками:
• Может хранить один произвольный объект в один момент времени.
• Объект можно получить и разместить на хранение в любой момент времени.
• Если объект забирают из коробки – ссылку на этот объект необходимо обнулить.
• Если объект кладут в коробку, но она не пуста – необходимо выкинуть исключение.
• Имеет метод проверки на заполненность.
• Методы класса должны работать с тем типом данных, который был указан во время создания объекта.
Создайте Коробку которая может хранить целочисленное значение, разместите туда число 3. Передайте Коробку в какой-либо метод, извлеките значение, и выведите его на экран.

### Алгоритм решения
1. Создается универсальный класс `Box<T>`, где `T` — типовой параметр, задающий тип хранимого объекта.
2. Внутри класса объявляется приватное поле `value` типа `T` для хранения объекта.
3. Метод `isEmpty()` проверяет равенство поля `value` значению `null` (если `null` — коробка пуста).
4. Метод `put(T value)` сначала проверяет, пуста ли коробка. Если она не пуста, выбрасывается исключение `IllegalStateException`. Если пуста — значение сохраняется в поле.
5. Метод `get()` сохраняет текущее значение во временную переменную, обнуляет поле `value` (присваивает `null`) и возвращает временную переменную.
6. Добавляется вспомогательный метод `peek()` для чтения значения без обнуления (необходим для выполнения Задания 2.2).
7. В методе `main` создается объект `Box<Integer>`, в него кладется число 3.
8. Создается отдельный метод `printFromBox(Box<Integer> box)`, который извлекает значение через `get()` и выводит его на экран. Коробка передается в этот метод.
9. Демонстрируется работа защиты от переполнения: в непустую коробку пытаются положить новое значение, обрабатывается исключение.

## Задача 2
### Текст задачи
Без null. Создайте сущность Хранилище, которая обладает следующими характеристиками:
• Может хранить один произвольный объект в один момент времени.
• Хранилище неизменяемо.
• Объект кладется в Хранилище при его создании. В качестве объекта может быть сохранено также и значение null.
• Хранилище может вернуть ссылку на Объект.
• Если вместо объекта хранится null, необходимо вернуть какое-либо альтернативное значение.
• Метод получения значения должен работать с тем типом данных, который был указан во время создания объекта.
Выполните следующие задания:
• Создайте Хранилище чисел, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число 0.
• Создайте Хранилище чисел, положите туда значение 99. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должно быть число -1.
• Создайте Хранилище строк, положите туда значение null. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка “default”.
• Создайте Хранилище строк, положите туда значение “hello”. Передайте Хранилище в какой-либо метод, извлеките значение, и выведите его на экран. Альтернативой должна быть строка “hello world”.

### Алгоритм решения
1. Создается универсальный класс `NoNullStorage<T>`, где `T` — типовой параметр.
2. Объявляются два финальных (неизменяемых) поля: `value` (хранимое значение, может быть `null`) и `alternative` (альтернативное значение).
3. Конструктор принимает оба значения и инициализирует поля. Так как поля `final`, изменить их после создания объекта нельзя (выполнено условие неизменяемости).
4. Метод `get()` использует тернарный оператор: если `value` не равно `null`, возвращается `value`, иначе возвращается `alternative`.
5. В методе `main` создаются четыре объекта `NoNullStorage` с различными типами (`Integer`, `String`) и значениями, как указано в задании.
6. Создается универсальный метод `printStorage(NoNullStorage<T> storage)`, который принимает хранилище любого типа, вызывает `get()` и выводит результат на экран.

# Задание 2

## Задача 2
### Текст задачи
Поиск максимума. Создайте метод, принимающий набор Коробок из задачи 3.1.1 и возвращающий максимальное из их значений в формате double. Принимаемые методом Коробки могут быть параметризованы любыми видами чисел.

### Алгоритм решения
1. Создается класс `MaxBoxFinder` со статическим универсальным методом `findMax`.
2. Сигнатура метода: `findMax(List<? extends Box<? extends Number>> boxes)`. Использование масок типов (`? extends Number`) позволяет принимать список коробок с любыми числовыми типами (Integer, Double, Long и т.д.), так как `List<Box<Integer>>` не является подтипом `List<Box<Number>>`.
3. Внутри метода инициализируется переменная `max` значением `Double.NEGATIVE_INFINITY` (наименьшее возможное число) и булева переменная `found = false`.
4. В цикле перебираются все коробки из списка.
5. Для каждой коробки проверяется метод `isEmpty()`. Если коробка не пуста, из нее извлекается значение через `peek()` (чтобы не обнулять коробку), приводится к типу `double` с помощью `doubleValue()`.
6. Если полученное значение больше `max`, переменная `max` обновляется. Флаг `found` устанавливается в `true`.
7. После цикла проверяется флаг `found`. Если он равен `false` (все коробки были пусты), выводится сообщение и возвращается `Double.NaN`.
8. В методе `main` создаются коробки с разными типами чисел (42, 17.5, 900L) и одна пустая. Они помещаются в список, который передается в метод `findMax`.

# Задание 3

## Задача 1
### Текст задачи
Функция. Разработайте такой метод, который будет принимать список значений типа T, и объект имеющий единственный метод apply. Данный метод надо применить к каждому элементу списка, и вернуть новый список значений типа P, при этом типы T и P могут совпадать, а могут не совпадать. Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", а получите список чисел, где каждое число соответствует длине каждой строки.
2. Передайте в метод список со значениями: 1,-3,7, а получите список в котором все отрицательные числа стали положительными, а положительные остались без изменений.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только максимальные значения каждого из исходных массивов.

### Алгоритм решения
1. Создается интерфейс `FunctionTask.Transformer<T, P>` с единственным методом `P apply(T value)`.
2. Создаются три класса, реализующие этот интерфейс:
   - `StringLength` (`Transformer<String, Integer>`): возвращает длину строки через `value.length()`.
   - `AbsoluteValue` (`Transformer<Integer, Integer>`): возвращает модуль числа через `Math.abs(value)`.
   - `ArrayMax` (`Transformer<int[], Integer>`): находит максимальный элемент в массиве (если массив пуст, возвращает `Integer.MIN_VALUE`).
3. В классе `Main` создается универсальный метод `static <T, P> List<P> transform(List<T> source, FunctionTask.Transformer<T, P> t)`.
4. Внутри метода создается новый пустой список `ArrayList<P>`.
5. В цикле перебираются все элементы исходного списка `source`. Для каждого элемента вызывается метод `t.apply(item)`, результат добавляется в новый список.
6. Метод возвращает новый список. В `main` метод вызывается трижды с разными исходными списками и соответствующими объектами-трансформерами.

## Задача 2
### Текст задачи
Фильтр. Разработайте такой метод, который будет принимать список значений типа T и объект имеющий единственный метод test (принимает T и возвращает boolean). Верните новый список типа T, из которого удалены все значения не прошедшие проверку условием. Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и отфильтруйте все строки имеющие менее трех символов.
2. Передайте в метод список со значениями: 1,-3,7, и отфильтруйте все положительные элементы.
3. Передайте в метод список состоящий из массивов целых чисел, а получите список в котором будут только те массивы, в которых нет ни одного положительного элемента.

### Алгоритм решения
1. Создается интерфейс `FilterTask.Condition<T>` с единственным методом `boolean test(T value)`.
2. Создаются три класса, реализующие этот интерфейс:
   - `LengthAtLeast3` (`Condition<String>`): проверяет, что длина строки `>= 3`.
   - `IsPositive` (`Condition<Integer>`): проверяет, что число `> 0`.
   - `NoPositiveElements` (`Condition<int[]>`): перебирает массив, если находит положительный элемент — возвращает `false`, иначе `true`.
3. В классе `Main` создается универсальный метод `static <T> List<T> filter(List<T> source, FilterTask.Condition<T> c)`.
4. Внутри метода создается новый пустой список `ArrayList<T>`.
5. В цикле перебираются элементы исходного списка. Если `c.test(item)` возвращает `true`, элемент добавляется в новый список.
6. Метод возвращает отфильтрованный список. В `main` метод вызывается трижды с разными исходными данными.

## Задача 3
### Текст задачи
Сокращение. Разработайте такой метод, который будет принимать список значений типа T и способ с помощью которого список значений можно свести к одному значению типа T, которое и возвращается из метода. Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: "qwerty", "asdfg", "zx", и сформируйте одну большую строку, которая состоит из всех строк исходного списка.
2. Передайте в метод список со значениями: 1,-3,7, и верните сумму всех значений исходного списка.
3. Имеется список, состоящий из списков целых чисел, получите общее количество элементов во всех списках. Подсказка: решить задачу можно в одно действие или последовательно использовать методы из 3.3.1 и 3.3.3. Далее необходимо изменить разработанный метод таким образом, чтобы данный метод гарантированно не возвращал null и не выбрасывал ошибок в том случае, если исходный список пуст.

### Алгоритм решения
1. Создается интерфейс `ReduceTask.Combiner<T>` с единственным методом `T combine(T left, T right)`.
2. Создаются классы, реализующие этот интерфейс:
   - `Concat` (`Combiner<String>`): склеивает две строки.
   - `Sum` (`Combiner<Integer>`): складывает два числа.
   - `ListSize` (реализует `Transformer` из 3.1): возвращает размер списка (используется для сценария 3).
3. В классе `Main` создается универсальный метод `static <T> T reduce(List<T> source, T identity, ReduceTask.Combiner<T> c)`.
4. Параметр `identity` — это начальное (нейтральное) значение (например, `""` для строк, `0` для суммы). Оно решает проблему пустого списка: если список пуст, цикл не выполнится, и метод вернет `identity`, а не `null`.
5. Переменная `acc` инициализируется значением `identity`.
6. В цикле перебираются элементы списка: `acc = c.combine(acc, item)`.
7. Возвращается накопленное значение `acc`.
8. Для сценария 3 (список списков) используется последовательное решение: сначала метод `transform` из 3.1 с `ListSize` превращает список списков в список их размеров, затем метод `reduce` с `Sum` суммирует эти размеры.
9. В `main` проверяется работа метода на пустом списке (возвращается `0`).

## Задача 4
### Текст задачи
Коллекционирование. Разработайте такой метод, который будет возвращать коллекцию типа P со значениями типа T. Данный метод будет принимать:
1. Список исходных значений.
2. Способ создания результирующей коллекции.
3. Способ передачи значений исходного списка в результирующую коллекцию.
Используйте разработанный метод следующим образом:
1. Передайте в метод список со значениями: 1,-3,7, и верните их разбитыми на два подсписка, в одном из которых будут только положительные числа, а в другом только отрицательные.
2. Передайте в метод список со значениями: “qwerty”, “asdfg”, “zx”, “qw” и верните их разбитыми на подсписки таким образом, чтобы в любом подсписке были строки только одинаковой длины.
3. Передайте в метод список со значениями: “qwerty”, “asdfg”, “qwerty”, “qw” и верните набор такого вида, который не может содержать одинаковые объекты.

### Алгоритм решения
1. Создаются два интерфейса:
   - `CollectTask.ResultFactory<R>` с методом `R create()` (отвечает за создание пустого контейнера).
   - `CollectTask.ResultWriter<R, T>` с методом `void add(R result, T value)` (отвечает за добавление элемента в контейнер).
2. Создаются реализации для каждого сценария:
   - Сценарий 1 (разбиение): `SplitFactory` создает `List<List<Integer>>` с двумя пустыми списками. `SplitWriter` проверяет знак числа и добавляет его в соответствующий подсписок.
   - Сценарий 2 (группировка по длине): `GroupByLengthFactory` создает `HashMap`. `GroupByLengthWriter` находит длину строки, проверяет, есть ли такая группа в словаре, если нет — создает новый список, затем добавляет строку в этот список.
   - Сценарий 3 (уникальные элементы): `SetFactory` создает `HashSet`. `SetWriter` просто добавляет строку, множество само отбрасывает дубликаты.
3. В классе `Main` создается универсальный метод `static <T, R> R collect(List<T> source, CollectTask.ResultFactory<R> factory, CollectTask.ResultWriter<R, T> writer)`.
4. Внутри метода вызывается `factory.create()` для получения пустого контейнера `R`.
5. В цикле перебираются элементы списка `source` и передаются в метод `writer.add(result, item)`.
6. Метод возвращает заполненный контейнер.
7. В `main` метод вызывается трижды с соответствующими фабриками и писателями.
