Пакет ru.surname.geometry
1. Файл Точка.java
Назначение файла:
Базовая сущность для описания координат. Используется во многих задачах: как угол для Квадрата (Задание 1.3), как вершины для Линии и Ломаной. Напрямую дорабатывается для Заданий 6.4 (сравнение) и 8.4 (клонирование).
Алгоритм работы:

Хранит два целочисленных поля x и y.

Конструктор инициализирует координаты.

Метод equals() переопределен для сравнения координат this.x == other.x && this.y == other.y.

Метод clone() переопределен (вызывает super.clone()) для создания независимой копии.

Метод toString() возвращает строку в формате {x;y}.

2. Файл Измеримый.java
Назначение файла:
Интерфейс для Задания 5.5. Описывает контракт: «любой объект, реализующий этот интерфейс, умеет вычислять свою длину».
Алгоритм работы:

Содержит единственный метод double длина(); без реализации. Все классы, которые его реализуют (Ломаная, Линия), обязаны написать этот метод.

3. Файл PolygonalChainProvider.java
Назначение файла:
Интерфейс для Задания 5.7. Описывает контракт: «объект умеет возвращать ломаную».
Алгоритм работы:

Содержит метод Ломаная getPolygonalChain();. Классы (Квадрат, Треугольник, Линия, Ломаная) реализуют его, возвращая объект типа Ломаная. Круг этот интерфейс не реализует.

4. Файл Ломаная.java
Назначение файла:
Сущность «Ломаная линия». Используется в Заданиях 1.3 (контур квадрата), 3.2 (базовый класс), 5.5 (измерение), 5.7 (объединение), 6.4 (сравнение).
Алгоритм работы:

Хранит список точек List<Точка> точки.

Конструктор принимает переменное число точек (varargs) и проверяет, что их не меньше двух.

Реализует метод длина() (из интерфейса Измеримый): в цикле суммирует расстояния между парами соседних точек.

Реализует метод getPolygonalChain() (возвращает this).

Переопределяет equals(): сравнивает списки точек через встроенный метод equals() коллекций List.

5. Файл ЗамкнутаяЛоманая.java
Назначение файла:
Подвид Ломаной для Задания 3.2. Гарантирует, что линия замкнута (начало совпадает с концом).
Алгоритм работы:

Наследуется от Ломаная.

В конструкторе вызывает super(точки) и проверяет, что getТочка(0).equals(getТочка(размер()-1)). Если нет — выбрасывает исключение.

Переопределяет длина(): берет длину обычной ломаной и добавляет расстояние между первой и последней точкой.

6. Файл Линия.java
Назначение файла:
Сущность «Отрезок». Используется в Заданиях 5.5 и 5.7.
Алгоритм работы:

Хранит две точки: начало и конец.

Реализует длина() (через статический метод расчета расстояния из класса Ломаная).

Реализует getPolygonalChain() (возвращает новую Ломаную из двух точек).

Переопределяет equals() (сравнивает начало и конец) и toString().

7. Файл Фигура.java
Назначение файла:
Абстрактный базовый класс для Задания 4.4. Объединяет все геометрические фигуры.
Алгоритм работы:

Содержит абстрактный метод double площадь();. Никакой реализации нет. Наследники обязаны сами посчитать площадь.

8. Файл Круг.java
Назначение файла:
Сущность «Круг» для Задания 4.4.
Алгоритм работы:

Наследуется от Фигура.

Хранит центр (Точка) и радиус (double). Конструктор проверяет радиус (> 0).

Реализует метод площадь() по формуле Math.PI * радиус * радиус.

9. Файл Квадрат.java
Назначение файла:
Сущность «Квадрат». Закрывает сразу три задания: 1.3 (инкапсуляция), 4.4 (фигура) и 5.7 (ломаная).
Алгоритм работы:

Наследуется от Фигура, реализует PolygonalChainProvider.

Хранит угол (Точка) и сторону (int).

Метод setСторона() проверяет сторона > 0 (инкапсуляция из 1.3). Конструктор вызывает этот сеттер.

Реализует площадь(): возвращает сторона * сторона.

Реализует getPolygonalChain(): вычисляет 4 угла квадрата, создавая 4 новые Точки на основе координат угла и стороны, и возвращает из них Ломаную.

10. Файл Прямоугольник.java
Назначение файла:
Сущность «Прямоугольник» для Задания 4.4.
Алгоритм работы:

Наследуется от Фигура.

Хранит угол и две стороны (double). Конструктор проверяет стороны (> 0).

Реализует метод площадь(): перемножает две стороны.

11. Файл Треугольник.java
Назначение файла:
Сущность «Треугольник» для Заданий 4.4 и 5.7.
Алгоритм работы:

Наследуется от Фигура, реализует PolygonalChainProvider.

Хранит три точки.

Реализует метод площадь() по формуле Герона: вычисляет длины всех сторон, находит полупериметр и применяет формулу с квадратным корнем.

Реализует getPolygonalChain(): возвращает Ломаную из 4 точек (три вершины и замыкающая точка).

Пакет ru.surname.tree
12. Файл Узел.java
Назначение файла:
Сущность для создания бинарного дерева в Задании 2.4.
Алгоритм работы:

Хранит значение (Integer), родителя и двух потомков.

Метод добавить(): если значения нет — записывает. Если новое больше — рекурсивно идет вправо (создавая потомка), иначе — влево.

Метод содержит(): рекурсивный поиск значения (идет направо, если искомое больше, и налево, если меньше).

Метод удалить(): если узел без потомков — просто стирает значение. Если один потомок — переносит его данные на место текущего. Если два — находит минимум в правом поддереве, копирует его значение в текущий узел, а затем удаляет минимум. Это сохраняет структуру дерева.

Метод toString(): выполняет Pre-order обход (сначала выводит текущий узел, затем левый, затем правый).

Пакет ru.surname.main
13. Файл Main.java
Назначение файла:
Точка входа (Задание 7.2). Содержит дружественный интерфейс (меню) для вызова всех задач. Внутри лежат общие методы и вложенные классы-задачи.
Алгоритм работы:

В начале метода main проверяется массив args (аргументы командной строки). Если там есть 2 элемента, вызывается метод степень() (Задание 7.3).

Запускается бесконечный цикл while(true), который выводит меню и считывает выбор пользователя (Scanner).

В switch в зависимости от выбора вызывается один из статических методов выполнить() вложенных классов (Задача1–Задача8).

Метод суммарнаяДлина() (5.5) принимает массив объектов Измеримый, проходит по нему циклом и суммирует результаты метода длина().

Метод объединить() (5.7) принимает массив объектов PolygonalChainProvider, собирает все их точки в один список и создает из него новую Ломаную.

Метод степень() (7.3) использует статические импорты pow и parseInt для возведения числа X в степень Y.

Вложенные классы (Задача1_Квадрат и т.д.) содержат готовые сценарии: они создают объекты с данными из условий, вызывают нужные методы и выводят результаты в консоль.
